# TrackHub — Android музыкальный сервис

TrackHub — учебный прототип музыкального сервиса для Android. Приложение позволяет регистрироваться, входить в аккаунт, загружать аудиотреки, слушать их, ставить лайки, оставлять комментарии, создавать плейлисты, искать треки и пользователей, подписываться на других пользователей.

## 1. Состав проекта

Проект состоит из двух частей:

```text
Android-клиент → FastAPI backend → PostgreSQL → файловое хранилище аудио
```

Основные технологии:

```text
Android: Kotlin, Jetpack Compose, ExoPlayer, OkHttp
Backend: Python, FastAPI, SQLAlchemy
Database: PostgreSQL
Storage: локальная папка uploads/tracks
Auth: JWT Bearer Token
```

## 3. Запуск backend

Перейдите в папку backend-проекта:

```bash
cd ~/trackhub_backend_mvp
```

Активируйте виртуальное окружение:

```bash
source .venv/bin/activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

Запустите backend:

```bash
uvicorn app.main:app --reload
```

Backend должен запуститься по адресу:

```text
http://127.0.0.1:8000
```

Swagger-документация доступна здесь:

```text
http://127.0.0.1:8000/docs
```

## 4. Запуск базы данных

Если PostgreSQL установлен локально, проверьте, что сервис запущен:

```bash
sudo service postgresql start
```

или:

```bash
sudo systemctl start postgresql
```

Параметры подключения должны совпадать с настройками backend-проекта. Обычно они находятся в `.env` или в файле `app/database.py`.

## 5. Запуск Android-приложения

Откройте Android-проект в Android Studio.

Проверьте, что в `app/build.gradle.kts` есть зависимость OkHttp:

```kotlin
implementation("com.squareup.okhttp3:okhttp:4.12.0")
```

Если используется обычный `build.gradle`, строка должна быть такой:

```gradle
implementation 'com.squareup.okhttp3:okhttp:4.12.0'
```

После этого выполните:

```text
Sync Project with Gradle Files
Build → Rebuild Project
Run
```

## 6. Адрес backend для Android

В Android-коде сейчас используется адрес:

```kotlin
private const val BASE_URL = "http://10.0.2.2:8000"
```

`10.0.2.2` — это специальный адрес, через который Android Emulator обращается к `localhost` компьютера.

Если приложение запускается на реальном телефоне, этот адрес нужно заменить на IP-адрес компьютера в локальной сети, например:

```kotlin
private const val BASE_URL = "http://192.168.1.10:8000"
```

При запуске на реальном телефоне компьютер и телефон должны быть в одной Wi-Fi сети, а firewall не должен блокировать порт `8000`.

## 8. Проверка сохранения авторизации

После входа токен сохраняется локально в `SharedPreferences`.

Проверка:

```text
1. Войти в аккаунт.
2. Полностью закрыть приложение.
3. Открыть приложение снова.
4. Пользователь должен остаться авторизованным.
5. Нажать “Выйти из аккаунта”.
6. После выхода должен открыться экран входа.
```

## 9. Оптимизации

В проекте выполнены следующие оптимизации:

```text
Backend:
- устранены N+1 SQL-запросы;
- добавлены индексы под основные сценарии;
- добавлены денормализованные счётчики;
- stream endpoint освобождён от подсчёта прослушиваний;
- добавлен отдельный endpoint для play_count;
- загрузка файлов выполняется чанками;
- разрешены только MP3 и WAV;
- добавлен is_liked для корректного отображения лайков текущего пользователя.

Android:
- сетевой слой переведён на OkHttp;
- повторные запросы используют connection pooling;
- добавлены key в LazyColumn;
- убраны лишние полные перезагрузки списков;
- сохранение JWT-токена вынесено в SessionViewModel;
- авторизация сохраняется после перезапуска приложения;
- тяжёлые фоновые Canvas-декорации убраны со вторичных экранов.
```

## 10. Возможные проблемы

### Backend не запускается

Проверьте:

```text
- активировано ли виртуальное окружение;
- установлены ли зависимости;
- запущена ли PostgreSQL;
- правильно ли указан DATABASE_URL;
- свободен ли порт 8000.
```

### Android не видит backend

Проверьте:

```text
- backend запущен;
- в эмуляторе используется http://10.0.2.2:8000;
- на реальном телефоне указан IP компьютера;
- телефон и компьютер находятся в одной сети;
- firewall не блокирует порт 8000.
```

### Ошибка OkHttp

Проверьте, что в Gradle добавлена зависимость:

```kotlin
implementation("com.squareup.okhttp3:okhttp:4.12.0")
```

После добавления зависимости выполните:

```text
Sync Project with Gradle Files
Build → Rebuild Project
```
